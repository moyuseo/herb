## 1. 产品概述

中药材行业行情网站——面向中药材产业链上下游（种植户、经销商、药企、采购商）的一站式行情信息服务平台。核心解决中药材价格不透明、供需信息不对称、行业资讯分散三大痛点，提供实时行情、历史走势、供求撮合、品种百科等专业服务。

- 目标用户：中药材种植户、经销商、药企采购、行业研究员
- 市场价值：成为中药材行业的"东方财富网"，构建数据驱动的行业决策入口

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 游客 | 无需注册 | 浏览行情、资讯、百科 |
| 普通用户 | 手机号注册 | 浏览全部内容、收藏品种、设置价格预警 |
| 供应商 | 手机号+资质认证 | 发布供应信息、企业店铺 |
| 采购商 | 手机号+资质认证 | 发布求购信息、获取联系方式 |
| 管理员 | 后台分配 | 内容管理、数据管理、用户管理 |

### 2.2 功能模块

1. **首页**：行情概览、涨跌排行榜、实时快讯、推荐供求、品种分类导航
2. **行情中心**：市场价格、产地价格、历史价格查询、价格走势图表
3. **品种详情**：品种基本信息、多规格价格、历史走势图、产地分布地图、相关资讯
4. **资讯中心**：品种分析、药市动态、集采资讯、政策法规、采购招标
5. **供求大厅**：供应信息列表、求购信息列表、发布供求、企业采购
6. **药材百科**：药材知识库、种植技术、功效与禁忌、药典标准
7. **数据中心**：价格指数、涨跌统计、产地热力图、行业报告
8. **用户中心**：我的收藏、价格预警、供求管理、个人设置

## 3. 核心流程

**行情查询流程**：用户进入首页 → 查看涨跌排行/搜索品种 → 进入品种详情页 → 查看价格走势/产地分布 → 收藏品种/设置预警

**供求撮合流程**：供应商发布供应 → 采购商浏览/搜索 → 查看详情 → 获取联系方式 → 线下交易

**资讯浏览流程**：用户进入资讯中心 → 按分类筛选 → 阅读文章详情 → 查看相关品种行情

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深绿色(#1B5E20)——象征中药材的自然与生命力，搭配金色(#C8A951)作为强调色
- **辅助色**：涨色红(#E53935)、跌色绿(#43A047)、中性灰(#78909C)
- **背景色**：浅米色(#FAF8F5)——营造传统中药铺的温暖质感
- **按钮风格**：圆角矩形(8px)，主按钮实心深绿，次按钮描边
- **字体**：标题使用"思源宋体"(Noto Serif SC)，正文使用"思源黑体"(Noto Sans SC)
- **布局风格**：顶部固定导航 + 左侧分类侧栏 + 主内容区卡片式布局
- **图标风格**：线性图标，2px描边，圆角端点
- **装饰元素**：中药材水墨插画作为页面装饰，传统纹样边框

### 4.3 响应式设计

- 桌面优先设计，断点：1200px(桌面) / 992px(平板横屏) / 768px(平板竖屏) / 480px(手机)
- 导航栏：桌面端水平导航，移动端汉堡菜单+侧滑导航
- 表格：桌面端完整表格，移动端卡片式列表
- 图表：桌面端大面积展示，移动端可滑动查看
- 地图：全宽展示，移动端支持手势缩放

### 4.4 设计理念

- **"本草堂"概念**：将传统中药铺的视觉元素融入现代UI设计
- 页面顶部装饰性水墨中药材插画
- 卡片边角使用传统纹样装饰
- 数据展示区使用宣纸质感背景纹理
- 品种详情页使用中药材手绘插图作为视觉锚点
